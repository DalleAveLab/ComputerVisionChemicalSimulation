README: Running `1st DEMO.ipynb`
This repository contains the notebook:
✅ 1st DEMO.ipynb
After downloading `1st DEMO.ipynb` from this GitHub repository (or cloning the repo), you can run it on your machine as follows:
1. Make sure you have Python and Jupyter Notebook installed.
2. Open a terminal (or Anaconda Prompt if using Anaconda).
3. Navigate to the folder where you saved/cloned the notebook.
4. Launch Jupyter with:

   jupyter notebook
5. In the browser window that opens, click on 1st DEMO.ipynb and run the cells.

That’s it — enjoy!
